# ConfigMan — Менеджер конфигураций

**ConfigMan** — это CLI-утилита на Go для управления конфигурациями в формате ключ-значение. Проект создан в учебных целях для отработки навыков разработки на Go, работы с файловой системой, JSON, CLI-интерфейсами и архитектурными паттернами.

## 🚀 Возможности

| Команда | Описание | Пример |
|---------|----------|--------|
| `set` | Сохранить или обновить конфигурацию | `configman set DB_HOST localhost` |
| `get` | Получить значение по ключу | `configman get DB_HOST` → `localhost` |
| `list` | Показать все сохранённые конфигурации | `configman list` |
| `delete` | Удалить конфигурацию по ключу | `configman delete DB_HOST` |
| `export` | Экспортировать конфигурации как переменные окружения | `configman -prefix MYAPP_ export` |

### 🔧 Флаг `--prefix`

Флаг `--prefix` позволяет добавить префикс к именам переменных при экспорте. Это удобно, когда нужно сгенерировать переменные окружения для конкретного приложения:

```bash
configman -prefix MYAPP_ export
# Вывод:
# export MYAPP_API_KEY="12345"
# export MYAPP_DB_HOST="localhost"
```

## 📦 Установка

### Требования

- Go 1.26.2 или выше

### Сборка из исходного кода

```bash
# Клонировать репозиторий
git clone https://github.com/Luxurymann/configman.git
cd configman

# Собрать бинарный файл
go build -o configman .

# (Опционально) Добавить в PATH для глобального доступа
# Linux/macOS:
sudo mv configman /usr/local/bin/
# Windows:
# Добавьте путь к бинарному файлу в переменную окружения PATH
```

### Быстрый старт

```bash
# Сохранить конфигурацию
./configman set api_key 12345

# Получить значение
./configman get api_key

# Посмотреть все конфигурации
./configman list

# Экспортировать как переменные окружения
./configman export
```

## 🏗 Архитектура проекта

```
configman/
├── main.go                    # Точка входа, CLI-интерфейс
├── go.mod                     # Модуль Go
├── storage.json               # Файл с конфигурациями (создаётся автоматически)
├── internal/
│   └── storage/
│       ├── file.go            # Работа с файловым хранилищем (JSON)
│       └── crypto.go          # Интерфейс для шифрования (задел на будущее)
```

### Ключевые компоненты

**`main.go`** — точка входа в приложение. Содержит:
- Парсинг аргументов командной строки
- Обработку флага `--prefix`
- Маршрутизацию команд (`set`, `get`, `list`, `delete`, `export`)

**`internal/storage/file.go`** — пакет для работы с хранилищем:
- `Storage` — структура, хранящая данные в памяти и синхронизирующая их с JSON-файлом
- `NewStorage(path)` — создание нового хранилища (если файл не существует, создаётся пустое)
- `Get(key)` / `Set(key, value)` / `Delete(key)` — CRUD-операции
- `List()` — получение всех пар ключ-значение
- `Export(prefix)` — экспорт в формате переменных окружения
- `Save()` / `Reload()` — синхронизация с диском

**`internal/storage/crypto.go`** — интерфейс для шифрования:
- `Cryptor` — интерфейс с методами `Encrypt` и `Decrypt`
- Позволяет в будущем добавить шифрование данных без изменения основной логики

## 🛠 Технологии

- **Язык:** Go 1.26.2
- **Формат данных:** JSON
- **Стандартная библиотека:** `flag`, `encoding/json`, `os`, `fmt`, `log`
- **Архитектура:** Clean Architecture (разделение на слои: CLI → бизнес-логика → хранилище)
